Baixe o app para Android

Toque no botão para baixar o instalador (APK) do MinutoCerto.

Baixar o app
Este app é só para Android. Abra esta página em um celular Android para baixar.

Prefere escanear?

Aponte a câmera do celular para o código.

Como instalar

  1. Baixe o arquivo e abra-o quando terminar.
  2. Se o Android pedir, permita instalar apps deste navegador (“Instalar apps desconhecidos”).
  3. Toque em Instalar e depois em Abrir.
